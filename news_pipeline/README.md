# איסוף חדשות ל"מה חדש בלונדון", שלב 0

בטא בטוחה: אוסף מועמדים ממקורות רשמיים וחינמיים, מסווג, מדרג ובודק עובדות, וכותב **טיוטות לבדיקה בלבד**.
אין פרסום, אין כתיבה לקבצי האתר, אין מודל שפה, אין תשלום ואין תזמון פעיל.

## הרצה

```bash
python3 news_pipeline/run.py --slot manual
```

דגלים עיקריים:

| דגל | מה עושה |
|---|---|
| `--slot morning\|evening\|manual` | שם החלון. משפיע על run_id ועל `--respect-slot` |
| `--respect-slot` | יוצא בלי לעשות דבר אם עכשיו לא 08:00 או 19:00 בשעון ישראל |
| `--fixtures DIR` | קורא קבצים מקומיים במקום רשת |
| `--now ISO` | זמן ריצה קבוע, לבדיקות ולשחזור |
| `--sources a,b` | רק מקורות מסוימים |
| `--out DIR` `--state DIR` | תיקיית פלט ותיקיית זיכרון. ברירת מחדל בתוך news_pipeline, ושתיהן ב-.gitignore |
| `--no-state-write` | לא מעדכן את הזיכרון בין ריצות |
| `--json` | שורת סיכום JSON בסוף, לחיבור ל-DS AI Operations |

קודי יציאה: 0 הושלם (כולל "אין מה לפרסם"), 1 שגיאת שימוש, 2 כל המקורות נכשלו.
`--mode publish` לא קיים ומחזיר 1.

## פלט

`out/<run_id>/`:

* `drafts.json`: טיוטות שהומלצו או ממתינות להחלטה. לכל אחת: עובדות עם evidence, ניקוד מפורט, הסיבות, בדיקת עובדות, הצעה לאייטם במבנה whats-new.json שבה כל שדה עברי ריק, ורשימת missing_fields.
* `decisions.json`: כל מועמד שנבדק, כולל הנפסלים והסיבה העיקרית.
* `report.md`: דוח קריא בעברית.
* `run.json`: תקציר, מצב כל מקור, יומן הבקשות, ומבנה handoff עם `requires_owner_approval: true` ו-`publish_allowed: false`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `run.py` | נקודת ההרצה היחידה |
| `fetch.py` | רשת לקריאה בלבד, robots.txt, בלי עקיפת חסימות |
| `sources/` | מתאם לכל מקור |
| `model.py` | מודל המועמד ושדותיו |
| `dates.py` | פענוח תאריכים עם evidence |
| `factcheck.py` | כל עובדה חייבת להופיע בטקסט המקור |
| `scoring.py` | דירוג לפי כללים, שערי פסילה ועצירה |
| `drafts.py` | טיוטות ודוח |
| `config.py` | כל הספים והמילונים |
| `../whats_new_dedup.py` | `classify()`: חדש, עדכון, ביטול, כפילות, פג תוקף. `check()` לא השתנה |
